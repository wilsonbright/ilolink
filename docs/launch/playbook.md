# ilolink — Product Hunt launch playbook

Self-hunt (you post as the maker). Everything staged before launch night; the
day-of is just execution.

---

## Timing

- **Post at 12:01am PT**, on a **Tuesday, Wednesday, or Thursday**.
  - 12:01 PT = start of the PH "day," so you get the full 24h ranking window.
  - Avoid Monday (crowded), Friday/weekend (low traffic).
- PH ranks on votes-over-time within that 24h window, so an early, steady stream
  beats a single late spike.
- **Pick the exact date, then set alarms** for 11:45pm PT (final check) and
  12:01am PT (post).

## Pre-launch (1–2 weeks out)

- [ ] Phase 0 security fixes deployed to production and spot-checked live.
- [ ] Listing finalized (`product-hunt.md`): tagline, description, topics, links.
- [ ] Assets finalized (`assets/`): thumbnail, 7 gallery images, GIF, social card.
- [ ] **Seeded demo doc published** and its URL dropped into the listing links.
- [ ] Soft-tease on your socials ("launching something next week for sharing AI
      output as a link") — build a little anticipation, no link yet.
- [ ] Line up your personal network (friends, small Slack/Discord groups) so you
      can *share the link* on the day. Never ask for upvotes — that's against
      PH rules and gets a launch penalized. "Hey, I launched this today" is fine.
- [ ] Prep the maker's first comment + canned answers in a doc you can copy from.
- [ ] Have a phone + laptop ready; the first 3–4 hours matter most.

## Day-of playbook

1. **12:01am PT — post it.** Submit as the maker (self-hunt). Double-check the
   thumbnail, gallery order, and that all links resolve.
2. **Immediately** paste the maker's first comment.
3. **Share the PH link** to your socials and relevant communities, framed as
   "we/I launched on Product Hunt today," with the link. Not "please upvote."
4. **Reply to every comment within minutes** for the first few hours. Use the
   canned answers as a base but keep each reply personal. Ask a question back —
   conversation drives ranking and goodwill.
5. **Mid-morning + evening nudges:** one more social post around 9am PT and again
   ~5pm PT ("still live, still answering questions"). Thank people by name.
6. **Watch the moderation queue** (`/admin/moderation`) during the traffic spike
   in case a published page gets abused — Phase 0 makes anonymous takedowns
   human-gated, so you're the backstop.
7. **End of day:** post a thank-you, note anything you shipped from feedback.

## PH rules to not trip over

- No asking for upvotes (DMs, group chats, "vote for me"). Share the link, let
  people decide.
- No incentivizing votes (giveaways tied to voting).
- One maker account; don't sockpuppet.
- Engage authentically in comments — PH weighs discussion.

## Assets-ready checklist (night before)

- [ ] Tagline + description + topics locked
- [ ] 7 gallery images (1270×760) in narrative order
- [ ] Thumbnail (240×240)
- [ ] Demo GIF plays and loops
- [ ] Social card (1200×630) for X/LinkedIn
- [ ] Maker's first comment + canned replies in a copy-ready doc
- [ ] Demo-doc URL live and in the listing
- [ ] Alarms set for 11:45pm and 12:01am PT
